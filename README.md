# 墨未干

> 他替死人擦名，直到自己的名字浮上纸面。

**题材**：奇幻 · 悬疑 · 职场　**作者**：灯下人　**14 章 · 40,583 字**

阴吏陆沉在酆都名籍司做了三百年擦名匠，专替亡者抹去阳世名籍。某夜，他发现自己专用的那本名册上多了一行未干的墨迹——他自己的名字。按规矩，名字出现即死期已定，他只有七天可活。陆沉一边照常上班擦别人的名，一边追查这本册子是谁写的。他翻遍司里的旧档，发现三百年前也有一个擦名匠遇到同样的事，那人选择擦掉自己，从此销声匿迹。陆沉最终没有擦，他把那一页留着，等着下一个接手的人看见。
